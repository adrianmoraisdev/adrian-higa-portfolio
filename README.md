## O que o site apresenta

- Posicionamento, números de impacto e disponibilidade
- Como uso agentes de IA (Claude Code e Codex) com governança, testes e revisão humana
- 8 cases com página própria: contexto, desafio, arquitetura, decisões técnicas, resultado e stack
- Infraestrutura em nuvem e DevSecOps que configurei e opero
- Experiência, stack e contato

Sistemas corporativos são apresentados sem telas, nomes de clientes ou endereços, por confidencialidade.

## Stack

Next.js 15 (exportação estática), React 19, TypeScript, CSS próprio e lucide-react.
Deploy automático no GitHub Pages a cada push na `main` (`.github/workflows/pages.yml`).

## Rodar localmente

```bash
npm ci
npm run dev
```

Conteúdo editável em `lib/site.ts` (perfil, métricas, experiência, stack) e `lib/cases.ts` (cases).
